# PE2 Long Case Cards

A personal flashcard and checklist app for a final-year Malaysian MBBS student preparing for Professional Exam 2 (PE2) long cases. It runs as an installable PWA from GitHub Pages on Android, iOS and Windows. The owner has ADHD: every feature should lower the effort to start and keep focus.

## Repo layout

Everything the site serves sits flat at the root. GitHub Pages serves the root, and nested app folders broke the icons once.

| Path | What it is |
|---|---|
| `index.html` | The whole app: HTML, CSS and vanilla JS in one file, no build step |
| `cards.js` | `window.DETAILS = [[name, history, exam, ix, mx, complications, keyfacts], …]` for 105 cases; `**bold**` marks key points |
| `sw.js` | Service worker, network-first. **Bump `CACHE` (`pe2-cards-vN`) on every release** or phones keep the old version |
| `manifest.webmanifest`, `app-*.png` | PWA install files |
| `banner-<specialty>.jpg/png` | Optional built-in specialty banners |
| `dev/claude-artifact/` | The same app as published on claude.ai (cloud sync via `window.claude` db and assets). Keep it in step with the root `index.html` |
| `dev/tools/` | Art and content generators (run from the repo root) |
| `dev/concept/project/` | Concept-art boards from the claude.ai design canvas (`.dc.html`), kept for reference |
| `dev/test/smoke.py` | Playwright smoke test |

## Run and test

```
python3 -m http.server 8765        # then open http://localhost:8765
python3 dev/test/smoke.py          # CHROME=/path/to/chrome to choose a browser
```

Check JS syntax after edits by extracting the `<script>` block and running `node --check` on it. Test at phone width (390 px) as well as desktop.

## Two versions of index.html

- **Root (standalone):** `STANDALONE` mode. Data lives in `localStorage` (`pe2-progress-v1`, `pe2-note-<id>`, …), pictures live in IndexedDB `pe2-pics`, and there is JSON backup and restore. It finds built-in banners by file name.
- **`dev/claude-artifact/index.html`:** the same code, but `connect()` uses `window.claude` (db at `data/users/<uid>/progress`, `/deck`, the `notes` collection; assets at `/_blob/<id>`). It is published from claude.ai, not from this repo. It also uses `icons/*.png`.

Apply every change to both files unless it only concerns sync or storage.

## Architecture (index.html)

- **Routing by hash:** start (empty hash; the app always opens here, and the hash is cleared on load), `home`, `cards`, `checklist`, `priority`, `approach`, `log`, `piggy`, `import`, `case-<id>`, `edit-<id>`/`edit-new`. `route()`, `render()` and `VIEWS`.
- **State:** `S = {exam, mood, dump, unl, done, conf, appr, pri, ban, act, piggy, log, wr}`, normalised by `norm()`, saved by `save()`.
  - `conf`: 1 Shaky / 2 Okay / 3 Solid.
  - `act[YYYY-MM-DD] = {r, d, n}`: rated, ticked and noted case ids.
  - `wr[caseId]`: sections written in Write mode.
  - `piggy = {amt, goals, ledger, moved, got, mine, wish}`.
- **Other stores:** deck edits in `DK = {edit, add, del}`; per-case notes in `NOTES` (7 sections plus pictures).
- **Specialty filter:** `fPost`, with `PNAME` mapping code to name.
- **Study buddies (Mochi and Sir Vixx):**
  - Art: `BUDDY_ART[kind][pose]`, SVG strings made by `dev/tools/buddy_gen.py`. `budArt()` adds streak unlocks (`UNL` tiers 3/7/14/30 days).
  - Behaviour: the state machine `budTick` (walk, idle, sit, hop, fall, fly, nap, react, scene), random facts from `pickFact()`, and interactions (tap, double-tap spin, long-press pat, fling, bonk, meet-up scenes).
- **Write mode (`WM`, `wmDraw`):** set up, write, snap the page, recall, done.
  - The writing screen embeds the desk scene `WS_SVG` with `{{holes}}` and `WS_LIGHT` time-of-day palettes. They are generated by `dev/tools/scene_write.py` and then `dev/tools/export_scene.py`, which writes `dev/tools/wscene.js`; paste its two constants over the ones in `index.html`.
  - `wmScene()` fills the holes; `wsTap()` handles the scene's hit buttons.
- **Other features:**
  - Just start missions: `startMission`, sized by mood via `missionN()`.
  - Piggy bank: `piggyEarn` / `piggyCheck`.
  - Side goals tab `#gtab` (custom goals, preset goals, savings goal).
  - Brain dump tab `#dtab`.
  - Break reminders: `studyMs`, `brk`.
  - Focus sounds: WebAudio rain, café and lo-fi, all generated in code. `sndSync()` plays them only during Write mode or a mission.
  - Exam countdown and mood check-in on the start screen.
  - Dates strip under the header (`dpillUpdate`, `dpopDraw`): PE2 (`S.exam`) plus up to 4 more (`S.dates`).
  - Spaced repetition: `srsRate()` runs from `logAct('r', …)`; `S.srs[id] = {due, iv}` (Shaky 1 day, Okay 3, Solid 7 then doubling to 60). `fDue` filter in Cards; Just start prefers due cards.
  - Study modes inside the Cards tab via `segHTML()` (one scrollable row): `#drill` (`DDX` differential lists, scores in `S.drill`; Drill · All · + Add chips; the owner edits built-in signs via overrides in `S.ddxEdit`, with Reset, and adds her own in `S.myddx`; always read them through `ddList()`/`ddFind()`) and `#signs`, labelled Ix interpretation (owner's own photos in `S.signs`, each with a `type`: sign, ecg, xray, abg, mnemonic, other).
  - Videos (`#videos`, `viewVideos`): saved video links in `S.vids` (links only; the owner chose not to store video files). Each link can have a topic picked from the case systems (Cardiology, Respiratory…), with topic filter chips, and optional notes shown under the title. YouTube links show their thumbnail (`ytId()`, i.ytimg.com); other links and failed loads fall back to a pastel card.
  - Rehearse (`#rehearse`, `viewRehearse`, state `RH`, actions `rhAct`, saved in `S.reh = {lc, mock, p60, mins}`), the second item in `segHTML()`:
    - Long case: pick or shuffle a case (`rhPick` prefers due, shaky and priority), timed stages `RSTG` (History, Examination, Prepare, Present; minutes adjustable in `S.reh.mins`), the `SEQ` presentation order from Prepare onwards, then the `RCHK` self-check, the card to compare, and a rating that feeds `logAct`.
    - Mock exam day: a long case, then 5 weakest `DDX` signs (Got it/Missed sets `S.drill`), then a random timed physical exam from `exList()`, then a summary.
    - 60-second present: one-minute countdown, three quick checks, rating, next case.
    - Mnemonic quiz: up to 5 of the owner's mnemonic pictures, weakest first; Got it/Missed sets their `conf`.
  - Pasting pictures: every picture spot (case pictures, Ix interpretation, banners, Write mode snap) takes Ctrl/Cmd+V (`paste` listener, `pasteWhere()`, `usePasted()`). The owner chose no Paste buttons.
  - Checklist tab switch (`segCHK`): Cases and `#exams` Physical exam (timed examination routine checklists in `EXR`, best times in `S.exr`). The owner can add her own exams (`S.myexr`), add steps, and edit built-in ones (overrides in `S.exrEdit`, with Reset); `exList()`/`exFind()` merge them.
  - Daily mnemonic (`mnemDaily`): once a day, on leaving the start screen, shows one of the owner's mnemonic pictures.
  - Wind-down mode 11pm–5am (`isWind`, `windSync`): dimmer screen, quieter sounds, missions capped at 3, one bedtime nudge; can be switched off for the night. The moon button in the header (`#dimbtn`, `pe2-dim` = on/off) dims or undims the screen at any time.
  - Black and white: the half-circle button in the header (`#bwbtn`, `bwSync()`, `pe2-bw` = on/off) puts `html.bw{filter:grayscale(1)}` on the whole app. It sits on `html` so fixed elements keep working.
  - Progress map of every case inside the Checklist progress panel (`mapHTML`).
  - "Open when Windows starts" steps on the home page (`winStartHTML`), shown only in the standalone app on Windows; the browser's own Start-app-when-you-sign-in setting does the work.

## Owner's preferences (follow these)

- **Look:** minimalist pastel UI in pink, purple and blue, with soft gradients. The home and start screens are white. Each specialty has its own pastel colour.
- **No code comments,** and **no explanatory helper text in the UI.** Keep labels short, and keep empty states to a couple of words.
- **Tabs:** at most 5 tabs in the top nav.
- **Ticking:** ticked checklist items stay in place. The goals tab shows only goals not done yet.
- **Medical content:** the differential lists in `DDX` are standard textbook causes. Follow current Malaysian MOH CPGs and the National Antimicrobial Guideline. All 15 priority cards are checked. Hyperthyroidism follows the MOH CPG Management of Thyroid Disorders (2019). Malaysia has no CPG for adult nephrotic syndrome or adult iron deficiency anaemia, so those follow KDIGO 2021 (glomerular diseases) and BSG 2021.
- **Copyright:**
  - Don't reproduce copyrighted characters or art; for example, the Lofi Girl was declined as a reference.
  - Don't commit the Surgery or Psychiatry banner pictures; the owner adds `banner-surgery.jpg` and `banner-psychiatry.jpg` herself.
  - Buddy art and scenes are original SVG.
- **Delivery:** keep all served files flat at the root, and bump the `sw.js` cache with each release.
